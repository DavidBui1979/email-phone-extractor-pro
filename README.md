# Email & Phone Number Extractor Pro 🚀

A powerful, fast, and privacy-focused Chrome Extension designed to extract, filter, and export emails and phone numbers from any web page or text into clean Excel, CSV, or TXT formats.

## 📖 Overview

**Email & Phone Number Extractor Pro** is a productivity tool built for sales professionals, marketers, recruiters, and researchers. It allows you to automatically gather contact information from active browser tabs or custom URLs without leaving your browser or sending data to external servers.

---

## ✨ Key Features

- **One-Click Page Scraping:** Instantly extract visible email addresses and phone numbers from your active tab.
- **Custom URL Fetching:** Enter any website URL to pull contact details directly.
- **Smart Filtering & Deduplication:** Automatically removes duplicate entries and organizes email addresses and phone numbers into clean, side-by-side columns.
- **Multiple Export Options:**
  - **Excel (.xlsx):** Native spreadsheet export via SheetJS.
  - **CSV (.csv):** Standard structured data export.
  - **TXT (.txt):** Plain text formatted export.
- **History Retention:** Retains your most recently extracted contacts locally so you never lose data.
- **Dark & Light Mode:** Built-in theme switcher for optimal visibility in any lighting condition.
- **100% Client-Side & Private:** All data processing and file generation happen entirely inside your browser. No tracking, no external API logging, and no server uploads.

## 📥 Installation Guide

1. Visit the official extension page on the [Chrome Web Store](https://chromewebstore.google.com/detail/ifmnibolelgnogmmdobbjokiakcbifmm/).
2. Click **Add to Chrome**.
3. Confirm the prompt to complete the installation.
4. Pin **Email & Phone Extractor Pro** to your Chrome toolbar for quick access.

---

## 🚀 How to Use

1. **Scrape Current Page:** Open any website and click **Scrape Page** to extract all emails and phone numbers on the active tab.
2. **Fetch Custom URL:** Enter a URL (e.g., `https://example.com/contact`) in the input box and click **Fetch URL**.
3. **Parse Raw Text:** Paste any raw text containing contact information into the text area and click **Extract Text**.
4. **Copy or Export:** Click **Copy** for individual columns or use **Export XLSX / CSV / TXT** to download your dataset.
